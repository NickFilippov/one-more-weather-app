@AGENTS.md

AGENTS.md holds the generic Expo/React Native rules (docs-first, `npx expo install`, CNG, EAS). This file records what is specific to this repo and what is true right now. If the two disagree about the current state of the code, this file wins.

## What this is

OneMoreWeatherApp: a pet-project weather app for iPhone and Android (Expo SDK 58, React Native 0.88, React 19.3, TypeScript strict). The sky fills the whole screen and changes with weather and time of day; data sits on glass panels in the style of iOS 26 Liquid Glass. README.md is in Russian; keep user-facing copy in Russian too.

**Status (2026-10-26):** the design is finished, the code is not started. `App.tsx` is still the Expo starter ("Open up App.tsx to start working on your app!"). None of the features in the README checklist exist in code. No weather data source has been chosen.

## Commands (checked against this repo)

- npm is the package manager (`package-lock.json`, no `bun.lock`), so `npx`, not `bunx`.
- Install packages with `npx expo install <pkg>` only.
- `npm start`, `npm run ios`, `npm run android`, `npm run web`.
- Typecheck: `npx tsc --noEmit` (passes on the starter; `tsconfig.json` extends `expo/tsconfig.base` with `strict`).
- Lint: AGENTS.md says to run `npx expo lint`, but ESLint is not a dependency and has no config. Expect an ESLint setup prompt on first run, not a lint pass. Set it up deliberately if you want lint to gate work.
- `npx expo-doctor` and `npx expo install --fix` work for dependency checks.

## Config gotchas

- `app.json` has `"userInterfaceStyle": "light"`. The design's day/night theme follows sunrise and sunset in the selected city, not the OS theme. Reconsider this setting and `<StatusBar style="auto" />` when theming is wired up.
- Icons, splash and the adaptive-icon background (`#E6F4FE`) are Expo template defaults.
- `LICENSE` is MIT with Expo's copyright line, left over from the template.
- `react-native-web` is installed and `npm run web` exists, but the design targets phones only.

### Rules that matter for the React Native port

- **One design for both platforms.** Same screens, layout, colours, components and animations. Only the glass material differs. Switch on `isLiquidGlassAvailable()` from `expo-glass-effect` (iOS 26+: `GlassView`), not on `Platform.OS`. Otherwise use frosted glass: a `BlurView` from `expo-blur` plus the `glass-frosted` tint, no specular highlight. Check the `expo-blur` Android notes in the SDK 58 docs before relying on it.
- **Fonts.** Temperature figures use Bricolage Grotesque (weight 200, tabular figures). All other text uses the system font (SF Pro / Roboto): do not set `fontFamily` for it.
- **Safe area** insets replace the fixed paddings used in the mockups (62px top on iPhone, 48px on Android; footer 28px from the bottom).
- **Reduced motion:** with `AccessibilityInfo.isReduceMotionEnabled`, drop rain, cloud drift and the count-up, and reduce entrances to a fade.
- **Day/night** comes from sunrise and sunset of the selected city. Each city card in the list has its own theme.
- **Copy:** impersonal, no emoji, typographic minus (`−3°`), degree sign without a space (`17°`). Warning colour (`alert`) always comes with words.
- Accent colours `rain`, `cold`, `warm` are for marks only, never for text; `text-muted` must not sit directly on `sky-top`.

### What to build

Components: `Atmosphere` (full-screen sky with rain canvas, clouds, sun/moon glow), `GlassPanel`, `GlassButton` (56 px footer, 44 px header), `PageDots`, `TempHero` (count-up from 0), `HourlyForecast`, `DailyForecast` (range bars, "now" dot), `WeatherIcon` (7 animated 32×32 glyphs: sun, moon, partly, cloud, rain, storm, snow). Patterns: tiles grid, city card (sky inside, own theme), search field.

Screens: main (hero, hourly, 10-day, tiles, footer), night, storm (with warning panel), cities (back, edit, search, city cards). Footer: precipitation-map button, page-dots pill, city-list button.

Dependencies the design implies and that are not installed yet: `expo-glass-effect`, `expo-blur`, `expo-linear-gradient`, `react-native-reanimated`, `expo-font`, `expo-symbols`, `expo-router`, plus `react-native-svg` for the weather icons (that last one is my suggestion, not from the design). Each addition goes through `npx expo install`. Native modules need a development build, not Expo Go; check each against the SDK 58 docs.
