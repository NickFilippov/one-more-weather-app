# 04. Нефункциональные требования

Числовые целевые значения предложены аналитиком и ждут подтверждения автора. Они задают ориентир для приёмки, а не результат измерений: приложение ещё не собрано.

| ID | Категория | Требование | Как проверить | Приоритет |
| --- | --- | --- | --- | --- |
| NFR-01 | Платформы | Один код и один дизайн для iPhone и Android. Различаются только материал стекла и системный шрифт текста. | сравнить экраны на обеих платформах с макетами | Must |
| NFR-02 | Платформы | Минимальные версии iOS и Android определены и записаны в документации (Q-05). | проверить `app.json` и документацию Expo SDK 58 | Must |
| NFR-03 | Платформы | Если доступен Liquid Glass (iOS 26 и новее), панели рисуются им. Иначе используется матовое стекло с тёмной тонировкой. Выбор делается по наличию возможности, а не по названию платформы. | запустить на iOS 26 и на устройстве без Liquid Glass | Must |
| NFR-04 | Производительность | От нажатия на иконку до отображения главного экрана с последними сохранёнными данными проходит не больше 2 секунд на устройстве среднего класса. | замер на реальном устройстве | Should |
| NFR-05 | Производительность | Анимации неба и прокрутка идут без заметных рывков (цель 60 кадров в секунду на актуальных устройствах). Размытие и частицы дождя не должны делать экран тормозящим на устройствах среднего класса. | замер кадровой частоты, проверка на бюджетном Android | Should |
| NFR-06 | Производительность | Когда приложение свёрнуто или экран перекрыт, фоновые анимации останавливаются, чтобы не тратить заряд. | проверить профилировщиком | Should |
| NFR-07 | Данные | Данные, которые видит пользователь, не старше 30 минут при наличии сети. Время последнего обновления известно приложению. | подменить ответы сервера и проверить | Must |
| NFR-08 | Данные | Без сети приложение показывает последние сохранённые данные с пометкой, когда они получены (Q-04). | отключить сеть | Should |
| NFR-09 | Надёжность | Ошибка сети, пустой или неполный ответ поставщика не приводят к падению. Пользователь видит понятное состояние (FR-18). | подменить ответ ошибкой, обрезать поля | Must |
| NFR-10 | Доступность | Контраст основного текста на стекле не ниже 4.5:1 в обеих темах и на всех состояниях неба; крупного текста не ниже 3:1. Дизайн-система проверила это для статичных состояний. | проверить на готовых экранах | Must |
| NFR-11 | Доступность | При включённом «Уменьшении движения» дождь, дрейф облаков и отсчёт температуры выключены, появление элементов сводится к проявлению. | включить настройку в системе | Must |
| NFR-12 | Доступность | У каждой кнопки без текста и у значимых блоков есть подпись для VoiceOver и TalkBack («Назад», «Карта осадков», «Список городов», «Штормовое предупреждение, подробнее»). Состояние погоды в иконках озвучивается словами. | пройти экраны с экранным диктором | Must |
| NFR-13 | Доступность | Размеры нажимаемых элементов не меньше 44 на 44 пунктов. Текст следует настройке размера шрифта в системе. | проверить на макете и при максимальном размере шрифта | Should |
| NFR-14 | Приватность | Геолокация запрашивается только по действию пользователя или при первом входе с объяснением, используется только для погоды и не отправляется никуда, кроме поставщика данных, и только с минимально нужной точностью. Достаточно приблизительного местоположения. | изучить разрешения и сетевые запросы | Must |
| NFR-15 | Приватность | Приложение не собирает личных данных и не требует регистрации. Хранится только список городов и порядок. | изучить хранилище | Must |
| NFR-16 | Безопасность | Ключи доступа к поставщику данных не лежат в репозитории. Если ключ платный или ограниченный по числу запросов, запросы идут через прокси (Q-02). | проверить репозиторий и сборку | Must |
| NFR-17 | Локализация | Интерфейс на русском языке. Тексты хранятся отдельно от разметки, чтобы позже добавить языки (Q-03). | просмотр кода | Should |
| NFR-18 | Сопровождаемость | Значения оформления (цвета, отступы, радиусы, длительности) лежат в одном месте и соответствуют токенам дизайн-системы. | сравнить с `tokens.json` дизайн-системы | Should |
| NFR-19 | Сопровождаемость | Перед завершением задачи проходят проверка типов (`npx tsc --noEmit`) и проверка зависимостей (`npx expo-doctor`). Линтер нужно настроить: сейчас ESLint в проекте нет. | запуск команд | Should |
| NFR-20 | Совместимость | Зависимости ставятся только командой `npx expo install`, чтобы версии подходили к Expo SDK 58. Для модулей с нативным кодом используется development build. | просмотр `package.json` | Must |

## Что здесь пока не определено

- Минимальные версии ОС (NFR-02): определяются возможностями Expo SDK 58 и выбранных модулей; значения нужно взять из документации.
- Поведение без сети (NFR-08): автор не решал, нужно ли это в первой версии (Q-04).
- Размер установочного файла, поддержка планшетов и режим устройства в альбомной ориентации не рассматривались: `app.json` фиксирует портретную ориентацию.
