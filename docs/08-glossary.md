# 08. Глоссарий

| Термин | Значение |
| --- | --- |
| Небо | фоновый слой экрана: градиент, облака, дождь, солнце или луна. Меняется с погодой и временем суток |
| Стекло, стеклянная панель | полупрозрачная поверхность с размытием фона, тонкой кромкой и тенью, на которой лежат данные |
| Liquid Glass | материал интерфейса iOS 26 и новее: стекло, которое преломляет фон и реагирует на касание |
| Матовое стекло | запасной материал там, где Liquid Glass нет (Android, iOS до 26): размытие с тёмной тонировкой |
| Тема дня и ночи | набор цветов, зависящий от локального времени города. Не связан с настройкой тёмной темы телефона |
| Дизайн-система | описание токенов, правил и компонентов оформления приложения |
| Токен | именованное значение оформления: цвет, отступ, радиус, длительность |
| Макет | экран, нарисованный в виде веб-прототипа; не работающее приложение |
| Гид по макетам | страницы с подписями, что где находится и по чему можно нажимать |
| Safe area | безопасная зона экрана без выреза и системных панелей |
| Шанс осадков | вероятность осадков в процентах |
| Шкала температур | полоска в прогнозе на 10 дней, показывающая диапазон дня на фоне диапазона всех дней |
| Текущее местоположение | город, определённый по геолокации устройства |
| Expo | платформа и набор инструментов для разработки приложений на React Native |
| Expo Go | готовое приложение для запуска проектов Expo; не поддерживает модули с нативным кодом, которых в нём нет |
| Development build | собственная сборка приложения для разработки, в которую включены нужные нативные модули |
| CNG (Continuous Native Generation) | подход, при котором папки `ios/` и `android/` генерируются из `app.json` и плагинов, а не правятся вручную |
| EAS | облачные сервисы Expo для сборки, подписи и отправки приложений |
| MoSCoW | способ приоритизации: Must, Should, Could, Won't |
