# 03. Функциональные требования

В коде не реализовано ни одно из требований. Колонка «Дизайн» показывает, есть ли для требования макет: **есть**, **частично**, **нет**. Подробности по экранам смотри в [05](05-screens-and-navigation.md), по правилам и данным в [06](06-business-rules-and-data.md), критерии приёмки в [02](02-user-stories.md).

## Погода города

| ID | Требование | Приоритет | Истории | Дизайн |
| --- | --- | --- | --- | --- |

| FR-02 | Фон главного экрана — небо, соответствующее состоянию погоды: ясно, переменная облачность, облачно, дождь, гроза. Для снега состояния неба нет (Q-12). | Must | US-14 | частично |
| FR-03 | Тема экрана (день или ночь) определяется по восходу и закату выбранного города (BR-01). | Must | US-14 | есть |
| FR-04 | Лента часов на 24 часа вперёд: «Сейчас» и дальше по часам. В каждом пункте время, иконка, температура и шанс осадков, если он больше нуля. Лента прокручивается по горизонтали. | Must | US-02 | есть |
| FR-05 | Короткая текстовая сводка над лентой часов (BR-15). | Should | US-03 | есть |
| FR-06 | Прогноз на 10 дней: день, иконка, шанс осадков, минимум, максимум и шкала температур в общем масштабе; у «Сегодня» отмечена текущая температура (BR-06). | Must | US-04 | есть |
| FR-07 | Плитки дополнительных показателей по две в ряду: ощущается как, ветер, влажность, восход и закат, осадки. | Should | US-05 | есть |
| FR-08 | В каждой плитке пояснение одной строкой («Из-за ветра кажется холоднее»). | Could | US-05 | есть |
| FR-17 | Штормовое предупреждение: панель с заголовком, сутью и деталями; по нажатию открываются подробности. | Should | US-12 | частично |
| FR-19 | Карта осадков, открывается кнопкой в футере. | Could | US-13 | нет |
| FR-22 | Обновление данных: при запуске, при возврате в приложение, если данные старше 30 минут (NFR-07), и по запросу пользователя. | Must | US-01 | нет |

## Поведение и оформление

| ID | Требование | Приоритет | Истории | Дизайн |
| --- | --- | --- | --- | --- |
| FR-18 | Состояния, которые нужно показывать: загрузка данных, ошибка сети, данные недоступны, нет доступа к геолокации, пустой список городов, ничего не найдено в поиске. | Must | US-01, US-11 | нет |
| FR-21 | Анимации: дождь и дрейф облаков в небе, отсчёт температуры при открытии, каскадное появление панелей, рост шкал температур, реакция стекла на нажатие. При включённом «Уменьшении движения» всё сводится к плавному проявлению. | Should | US-15 | есть |
| FR-23 | Сплэш при запуске «Восход»: над горизонтом поднимается солнце (ночью луна), по одному слову всплывает название One More Weather App, затем небо раскрывается от точки восхода и температура вылетает навстречу на своё место главного экрана. Около 2.6 с, только при холодном запуске. При «Уменьшении движения» кадр с названием просто гаснет. | Should | US-15 | есть |

Приоритеты предложены аналитиком и ждут подтверждения автора. Больше всего риска в Must-требованиях без дизайна: FR-11 и FR-18.

## Что вне требований

Нужно решить до начала разработки соответствующих частей (подробно в [07](07-risks-and-open-questions.md)):

- источник данных (Q-02): от него зависят FR-01…FR-08, FR-10, FR-17, FR-20;
- как выбирается состав плиток (Q-07);
- что происходит при полярном дне и ночи, когда нет восхода или заката (Q-06).
